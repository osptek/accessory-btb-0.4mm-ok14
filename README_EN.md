## Overview

The OK-14 series are **0.4mm pitch BTB (board-to-board) connectors**. A header and a socket mate together at a height of 0.8mm.

| Type | Part number | Contacts |
|:--|:--|:--|
| Header | `OK-14GM` | 10, 12, 14, 16, 24, 30, 34, 40 |
| Socket | `OK-14F` | 10, 12, 14, 16, 24, 30, 34, 40, 50, 70 |

## Part numbering

Taking `OK-14GM024-04` as an example:

| Field | Meaning |
|:--|:--|
| `OK-14` | Series |
| `GM` / `F` | `GM` = header, `F` = socket |
| `024` | Number of contacts (24) |
| `-04` | Pitch 0.4mm |

## Specifications

| Item | Value |
|:--|:--|
| Pitch | 0.4mm |
| Mating height | 0.8mm |
| Rated voltage | 60V AC/DC |
| Rated current | 0.3A per contact (5A max total) |
| Insulation resistance | ≥ 1000MΩ (initial) |
| Withstanding voltage | 150V AC for 1 minute |
| Contact resistance | ≤ 90mΩ |
| Operating temperature | -55°C to +85°C |
| Storage temperature | -55°C to +85°C (product only); -40°C to +50°C (emboss packing) |
| Insertion force | ≤ 0.981N × contacts (initial) |
| Removal force | ≥ 0.165N × contacts |
| Post holding force | ≥ 0.49N |
| Mating cycles | 50 |
| Salt spray | 24 h mated: insulation ≥ 100MΩ, contact resistance ≤ 90mΩ |
| Housing | LCP (UL94 V-0) |
| Contacts | Copper alloy, Ni underplating, Au plated |
