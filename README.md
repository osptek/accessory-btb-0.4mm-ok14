## 产品简介

OK-14 系列是 **0.4mm 间距的 BTB（Board-to-Board）板对板连接器**，由公座和母座配对使用，配合后高度 0.8mm。

| 类型 | 型号 | Pin 数 |
|:--|:--|:--|
| 公座（Header） | `OK-14GM` | 10, 12, 14, 16, 24, 30, 34, 40 |
| 母座（Socket） | `OK-14F` | 10, 12, 14, 16, 24, 30, 34, 40, 50, 70 |

## 型号命名

以 `OK-14GM024-04` 为例：

| 字段 | 含义 |
|:--|:--|
| `OK-14` | 系列 |
| `GM` / `F` | `GM` = 公座（Header），`F` = 母座（Socket） |
| `024` | Pin 数（24Pin） |
| `-04` | 间距 0.4mm |

## 规格参数

| 项目 | 参数 |
|:--|:--|
| 间距 | 0.4mm |
| 配合高度 | 0.8mm |
| 额定电压 | 60V AC/DC |
| 额定电流 | 0.3A/Pin（总电流最大 5A） |
| 绝缘电阻 | ≥ 1000MΩ（初始） |
| 耐电压 | 150V AC，1 分钟 |
| 接触电阻 | ≤ 90mΩ |
| 工作温度 | -55℃ ~ +85℃ |
| 储存温度 | -55℃ ~ +85℃（产品）；-40℃ ~ +50℃（编带包装） |
| 插入力 | ≤ 0.981N × Pin 数（初始） |
| 拔出力 | ≥ 0.165N × Pin 数 |
| 固定脚保持力 | ≥ 0.49N |
| 插拔寿命 | 50 次 |
| 盐雾 | 公母配合 24 小时后，绝缘电阻 ≥ 100MΩ，接触电阻 ≤ 90mΩ |
| 胶芯材料 | LCP（UL94 V-0） |
| 端子 | 铜合金，镍底镀金 |
